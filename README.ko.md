# DeskPet - 바탕화면 정리 펫

[English](README.md) | **한국어**

삼색 고양이 또는 찹츄 리트리버가 바탕화면 위를 돌아다니면서,
바탕화면에 새로 저장된 파일을 "몰아서 들어온 것끼리" 폴더로 묶어 정리해줘요.

## 처음 한 번만: 준비

1. https://nodejs.org 에서 **LTS** 버전을 받아 설치해요. (설치 화면은 전부 "다음"을 눌러도 돼요)
2. 이 저장소를 내려받아요. (GitHub의 **Code → Download ZIP** 후 압축 풀기)
3. 폴더 안 빈 곳에서 **Shift + 마우스 오른쪽 클릭 → "터미널에서 열기"** (또는 "PowerShell 창 열기")를 눌러요.
4. 아래 명령어를 입력해요. 필요한 부품을 받아오느라 몇 분 걸릴 수 있어요.

```
npm install
```

## 바로 실행해보기 (EXE 만들기 전 테스트)

```
npm start
```

## EXE 만들기

```
npm run build
```

끝나면 `dist` 폴더 안에 **DeskPet.exe** 가 생겨요. 이 파일 하나만 다른 사람에게 주면,
받는 사람은 Node.js 없이 더블클릭으로 실행할 수 있어요.
(서명이 없는 앱이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.)

## 사용법

- 커서를 움직이면 따라오고, 8초 동안 가만히 있으면 졸아요.
- 캐릭터에 마우스를 올리면 오른쪽 위에 **X**가 생겨요. 누르면 숨어요.
- 캐릭터를 끌어서 원하는 곳에 옮길 수 있어요.
- 화면 오른쪽 아래 **트레이 아이콘**(작은 고양이 얼굴)을 누르면 다시 부르거나 설정을 바꿀 수 있어요.
  - 캐릭터 바꾸기 (삼색 고양이 / 찹츄 리트리버, 각각 일러스트 · 포근한 그림 중 선택)
  - 커서 따라다니기 켜기 / 끄기
  - 정리 잠깐 멈추기 (바탕화면에서 직접 작업할 때)
  - 새 묶음 기준 시간 (기본 20분)
  - 언어 (자동 / 한국어 / English)
  - 마지막 폴더 열기, 컴퓨터 켤 때 자동 실행, 종료

## 정리 규칙

- **바탕화면만** 지켜봐요. 사진·다운로드 폴더는 건드리지 않아요.
- 파일 종류는 가리지 않아요. 캡처, PDF, 문서 모두 똑같이 정리해요.
- 마지막 파일이 들어온 뒤 20분 안에 들어온 파일은 같은 폴더에 넣어요.
- 한동안 조용하다가 새 파일이 들어오면 캐릭터가 **"새 묶음이에요! 폴더 이름을 붙여줄래요?"** 하고 물어봐요.
  - 이름을 입력하고 Enter → 그 이름의 폴더에 저장, 예: `오늘 작업` (같은 이름 폴더가 있으면 거기에 이어서 넣어요)
  - 비워두고 저장, Esc, 또는 20초 동안 대답이 없으면 → `정리_10-04_1` 같은 날짜 폴더
  - **아까 폴더** → 바로 전 묶음에 이어서 넣기
- 앱 언어는 윈도우 언어를 따라 자동으로 정해지고, 트레이 메뉴에서 바꿀 수 있어요.
- 캐릭터를 숨겨둔 동안에는 묻지 않고 날짜 폴더로 정리한 뒤 윈도우 알림으로 알려줘요.
- 이런 파일은 건드리지 않아요: 바로가기, 다운로드 중이거나 임시 파일, 오피스 잠금 파일(`~$`),
  바탕화면에서 "새로 만들기"로 만든 `새 텍스트 문서` 같은 파일, 그리고 지금 열려 있는 파일.

## 개인정보

DeskPet은 개인정보를 수집하지 않고 인터넷으로 아무것도 보내지 않아요. 외부 연결은 코드에서 여러 겹으로 막혀 있어요. 화면의 보안 정책, 앱 전체의 요청 차단, 그리고 Electron 엔진의 백그라운드 통신(맞춤법 사전 다운로드, 업데이트 확인, 통계)까지 시작할 때 모두 꺼둬요.
저장하는 건 `%APPDATA%\desk-pet\config.json` 설정 파일 하나뿐이고, 파일 내용은 열지 않아요.
